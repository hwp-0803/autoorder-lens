# 고객 판매 / 운영 배포 전 점검표

## 현재 제공 수준

- 사용자에게 시연할 수 있는 UI, CSV 기반 예측 엔진, FRED 최신 확인, 편향 모니터, 모델 검증 및 다운로드 기능 포함
- 로컬 Windows PC에서 실행되는 Streamlit 앱. 고객 인증·접근 통제·회사별 데이터 격리는 **미구현**
- 데이터 원천은 미국 제조업 집계 **신규주문액**으로서 개별 사업장의 생산량 또는 수요 확정 주문이 아님
- 과거 2022~2026년 자료를 반복적으로 활용해 모델 및 경고 규칙을 선정했으므로 독립 검증 필요

## 필수 출시 게이트 (미충족이면 상용 운영 배포 보류)

- [ ] **상업적 데이터 이용 권한**: FRED 이용약관, UBTPNO 원 제공기관 권리, 상업 배포 및 데이터 표시 방식 검토. 데이터 제공계약 또는 별도 승인 필요한지 확인
- [ ] **접근 제어**: 조직별 로그인(SSO/OIDC), 권한, 감사로그, 비밀 관리, 전송구간 TLS 및 인프라 보안
- [ ] **멀티테넌트 분리**: 고객 조직별 자료·업로드·캐시·모델·파일 접근 격리. 현재 프로젝트는 단일 사용 환경 가정
- [ ] **실제 실무데이터 적합성**: 제조업 전체 신규주문액과 회사의 SKU별 주문/재고/납기/생산능력 자료 매핑 및 현장 담당자 검증
- [ ] **모델 품질**: 실시간 빈티지 데이터로 재현한 리드타임 검증, 경고 오탐/미탐 성능, 예측구간 캘리브레이션, 드리프트 대응 및 변경 승인 절차
- [ ] **데이터 수집 운영**: API 가용성, 발표 지연, 과거 수치 개정 감지, 오류 재시도, 출처·조회시각·이력 보관
- [ ] **성능/안정성**: 다중 사용자 부하·모델 학습 워커 분리, 캐시 수명, 동시 재학습 제한, 정기 백업, 장애 알림
- [ ] **책임 범위**: 서비스 이용약관, 수치의 단위·활용 제한 고지, 계약서 SLA, 지원 정책, 과금/환불 및 개인정보 처리(해당 시)

## 판매용 화면 문구 운영 원칙

- 고객에게는 **존댓말 / 간결하고 확인 가능한 서술문**으로 표시
- `경고 조건 미충족`은 **산업 수요가 정상이라는 판정이 아님**
- `95% 예측구간`은 **손실 상한이나 안전보장 범위가 아님**
- `시나리오`는 **사용자 가정**이며 모델이 자동 탐지한 외생 수요 변화가 아님
- FRED 데이터는 **수량이 아니라 명목 달러** 지표임
- 판매대상과 실제 운영 책임자는 데이터 이용권한, 원천 수정 및 릴리즈 시점에 접근 가능해야 함
