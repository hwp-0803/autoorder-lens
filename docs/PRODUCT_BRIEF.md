# AutoOrder Lens | 제품 소개 (고객용 초안)

## 월별 주문액 변화를 한 화면에서 확인하는 수요 인텔리전스

AutoOrder Lens는 미국 자동차 차체·트레일러·부품 제조업의 공개 신규주문액 시계열을 기반으로 **단기·장기 전망**, **예측 편향 모니터링**, **시나리오 비교**를 제공하는 분석 지원 대시보드입니다.

### 사용 대상

제조업 수요계획, 경영기획, 시장조사, 산업동향 분석 담당자. 회사별 발주/재고 최적화까지 제공하는 제품이 아니라 **공개 산업 지표를 수요 전망의 참고신호로 읽는 도구**입니다.

### 지원 기능

1. 월별 최신 관측치와 1개월 앞 / 12개월 연속 전망
2. 시장 관측치와 과거 예측 편향의 누적 패턴 모니터링
3. 가정 수요 변동률 입력에 따른 장기 전망 금액 영향 시뮬레이션
4. 모델 성능 비교와 데이터·예측 결과 CSV 내보내기
5. 데이터 출처·기간·모델 정책 표시

### 기술 및 데이터

- Python, Streamlit, Plotly, statsmodels
- 모델: SARIMA AR3 단기(연 1회 파라미터 재학습), SARIMA AR6 장기(예측 시작 시점 파라미터 재학습)
- 데이터: 미국 Census M3 신규주문액, 명목 백만 달러 / FRED UBTPNO

### 고객 시연 흐름 (3분)

1. **운영 개요:** 최근 관측, 전년 동월 대비, 다음 1개월 전망, 12개월 전망 합계
2. **전망:** AR3/AR6 예측 및 예측구간과 12개월 시나리오 변동률
3. **편향 모니터링:** 실제값 대비 예측오차, 2개월 주의·3개월 강화 경고 발생 이력
4. **모델 성능:** 근거가 되는 시계열 검증 데이터와 데이터 한계

### 유의사항

현재 버전은 **고객용 기능 시연·도입 검토가 가능한 제품형 프로토타입**입니다. 실제 서비스 판매 및 운영 도입은 데이터 이용권한, 인증·보안, 고객 조직별 데이터 검증, 성능 모니터링 및 계약 체계를 갖춘 후 진행해야 합니다.
