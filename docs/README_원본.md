# AutoOrder Lens — Demand Intelligence v3.1

미국 자동차 차체·트레일러·부품 제조업의 **신규주문액(명목 백만 달러)**에 대한 B2B 스타일 수요 전망·예측오차 모니터링 대시보드입니다.

## 1. 제품 범위

- **운영 개요:** 최신 공개 실적, 전년 동월 대비 증감, 단기·장기 전망, 상태 요약
- **수요 전망:** 단기 SARIMA AR3(1개월), 장기 SARIMA AR6(12개월), 80%·95% 모형 기반 예측구간, 과거 관측 그래프
- **시나리오:** 사용자가 지정한 ±15% 변동률을 장기 전망에 적용한 금액 민감도 분석. *학습된 확률적 전망이 아닙니다.*
- **편향 모니터링:** 실적 발표 후 2개월 주의 / 3개월 강화 경고. 과소예측·과대예측 모두 관찰
- **모델 성능:** 사전 산출된 CSV 연결 또는 월별 백테스트 재계산
- **데이터·운영:** 시계열 출처 및 정의, 모델 정책, 주의사항, CSV 내보내기

## 수요 전망 화면 옵션 가이드

- **과거 관측자료 표시기간**: 과거 신규주문액을 그래프에 몇 개월 표시할지 선택합니다. 24개월은 최근 2년, 60개월은 최근 5년이며 미래 12개월 전망·모델 학습·예측값은 변하지 않습니다.
- **미래 예측구간 80%·95%**: 모형 가정하의 미래 신규주문액 불확실성 범위입니다. 80%는 상대적으로 좁고 95%는 넓습니다. 모델 정확도 80%/95%라는 뜻이 아니며 실제 포함률 보정은 별도 검증이 필요합니다.
- **기본 전망 대비 주문액 변화 가정(−15%~+15%)**: 사용자 가정을 미래 12개월의 각 월별 AR6 예측액에 똑같이 적용하여 금액 차이를 계산합니다. 예를 들어 +10%는 12개월 기본 합계에 1.10을 곱합니다. 이 선택은 모델 기본 전망이나 예측구간을 바꾸지 않고 추가 자동 예측을 하지 않습니다.

버튼 옆 도움말과 '옵션 알아보기' 화면을 통해 앱에서도 같은 내용을 확인할 수 있습니다.

## 2. Windows 실행

1. `AutoOrder_Lens_Enterprise_v3.zip` 압축을 풉니다.
2. 내부 `automotive_forecast_dashboard` 폴더를 VS Code 프로젝트 또는 다른 작업 폴더에 둡니다.
3. `run_dashboard.bat`를 더블클릭합니다. 오류 발생 시 창이 닫히지 않도록 구성했습니다.
4. 브라우저에서 `http://localhost:8501`을 엽니다.

배치 파일 실행이 제한되면 현재 폴더에서 명령 프롬프트를 열고 다음을 실행합니다.

```cmd
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

**권장:** Python 3.12. 기설치된 Python3.12 라이브러리에 `statsmodels` 충돌이 있으면 새 가상환경을 만들어 설치하십시오.

## 3. 데이터 연결 및 단위

- 기본 모드: FRED `UBTPNO` 최신 CSV 조회. 업데이트는 FRED 제공 시점에 따라 지연될 수 있습니다.
- 오프라인 모드: `orders_clean.csv` 또는 `orders_backlog_inventory.csv`를 프로젝트 폴더(또는 상위 폴더)에 두거나, 사이드바에서 직접 CSV를 업로드하십시오.
- 로컬 CSV 형식: 날짜 열(`Month`, `DATE` 등)과 `orders`(**백만 달러**) 열을 포함합니다.
- 모델 비교 조건과 일치시키기 위해 **2005-02부터** 예측합니다.
- FRED에서 과거 시계열 값이 개정될 수 있으므로 기존 백테스트 CSV와 다른 경우 경고 기록을 제외하거나 다시 계산하도록 했습니다.

## 4. 모델 정책

- 단기 AR3: `SARIMAX(order=([3],1,1), seasonal_order=(0,1,1,12), trend='n')`, 2020년 4~7월 일회성 더미, **매년 1월 계수 재추정 후 실적 월별 갱신**.
- 장기 AR6: `SARIMAX(order=([6],1,1), seasonal_order=(0,1,1,12), trend='n')`, 동일한 더미·계절구조, **전망 시작 시점 실적까지 계수를 재추정 후 12개월 연속 예측**.
- 이 두 정책은 같지 않습니다. 장기 모델은 모든 달에 자동으로 매년 한 번만 학습하는 구조가 아닙니다.
- 데이터가 2026-08까지라면 2026-09 값은 달력상 과거 월이더라도 공개 전 실적 추정으로 표시합니다.

## 5. 검증 및 실행 조건

```bash
python -m pytest tests -q
python -m py_compile app.py forecast_engine.py evaluation_engine.py fred_data.py
```

과거 기간(2016~18, 2022~26)을 여러 번 탐색한 결과를 기준으로 모델과 경고 조건을 선정했습니다. 통계적·상업적 성능 보장, 미래 실시간 관측자료로 검증된 경고 신뢰도, 생산·재고 최적화 등을 보증하지 않습니다.

## 6. 배포 전 필수 사항

`docs/COMMERCIAL_READINESS.md` 확인. 인증·인가, 원천 데이터 상업적 이용 권한, 서버 보안·HTTPS, 모니터링, 도입기업 내 데이터 검증, SLA와 책임범위가 확인되어야 외부 고객 대상 운영 서비스가 가능합니다. **v3.1은 고객 시연과 파일 기반 도입 검토가 가능한 제품형 데모**입니다.

## 7. 파일 구성

- `app.py`: 화면·이벤트·차트·다운로드
- `forecast_engine.py`: SARIMA 학습, 예측, 알림 백테스트
- `evaluation_engine.py`: 과거 성능평가
- `fred_data.py`: FRED UBTPNO 월별 CSV 수집
- `.streamlit/config.toml`: 스타일·툴바 설정
- `docs/COMMERCIAL_READINESS.md`: 영업·운영 배포 점검표
- `tests/`: 계산 엔진 자동검사

**데이터 출처**: U.S. Census Bureau M3 via Federal Reserve Bank of St. Louis FRED, `UBTPNO`. 데이터의 상업적 사용 및 재배포 조건은 원 제공기관·FRED 약관을 직접 확인하십시오.
